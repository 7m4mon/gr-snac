# token保存の比較データ

SNAC tokenを1個12 bitで保存し、入力音声なしで復号できることと、保存サイズを確認するためのデータです。
同じSNACモデルの重みは復号側に別途必要です。`.snac`は独自形式で、一般の音楽プレイヤーでは再生できません。

このフォルダーの保存データは、1秒区間を独立処理する条件と、前後500 msの文脈もtokenに含める条件の比較です。
現行の中央フレームだけを送る方式の測定結果は[frame_stream_check](../frame_stream_check/README.md)を参照してください。

入力は206905 samples（8.621秒）の24 kHz mono音声です。

| 条件 | token数 | payload bit/s | 保存サイズ |
|---|---:|---:|---:|
| 前後500 msを含める | 1428 | 1987.69 | 2468 bytes |
| 独立区間・文脈なし | 728 | 1013.33 | 1416 bytes |

`encoded.snac`は文脈あり、`encoded_no_context.snac`は文脈なしの比較用です。
JSONにサイズの内訳、比較WAVに復元音声を保存しています。
文脈ありの保存ファイルだけから206905 samplesを復号できることを確認しました。
ここでの文脈の重複分やヘッダーを含む値は、現行の定常payload 984.375 bit/sとは異なります。
